Авторы

Ay_Emul сделали два человека из Хабаровска:

Сергей Бульба (svbulba@gmail.com) – автор.

Иван Решетников – основная графика.


Иконки предоставили Сергей Бульба, Иван Решетников, David Willis, bcass, X-agon, Graham Goring, Exocet и Роман Морозов.

Алгоритм эмуляции шума AY-3-8910 и YM2149F написан в соавторстве с Hacker KAY (Hacker KAY считал с генератора шума реальных микросхем полный массив битов, с помощью которого Сергей Бульба воссоздал принципиальную схему генератора).

Таблицы выходных уровней микросхем AY-3-8910 и YM2149F, измеренных на реальных микросхемах, сделал Hacker KAY.

Проигрыватели различных форматов написаны на основе проигрывателей и (или) описаний, принадлежащих авторам этих форматов или третьим лицам.

Для эмуляции MC68000 используется библиотека Starscream 680x0 emulation library by Neill Corlett (corlett@elwha.nrrc.ncsu.edu), с изменениями Stéphane Dallongeville и Carsten Elton Sørensen.

Для проигрывания некоторых YM2-файлов используются сэмплы из digidrum.cpp библиотеки Open Source ST-Sound Library by Arnaud Carré.

Ay_Emul умеет также работать с библиотеками BASS/BASSENC by Ian Luck и с базой длительности музыки SNDH из проекта sc68 by Benjamin Gerard (если соответствующие файлы находятся в папке с Ay_Emul).
