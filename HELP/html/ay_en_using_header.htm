"Information in the file header" dialog box

This box appears before converting single playlist item to VTX or YM6. Some fields available for VTX only. The dialog does not appear during group conversion, because all fields are filled in automatically from the playlist item settings.

Field Year must be either an integer number, or zero (or empty) value if unknown. All other fields like fields of "Mixer" and "List's item adjusting" dialog boxes.

Apply button saves settings and close the box.

Restore button restores all settings to previous values.
