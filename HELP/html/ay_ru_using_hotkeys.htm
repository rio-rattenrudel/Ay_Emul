Стандартные комбинации клавиш

Alt+F4Закрыть активное окно
TabПереход между группами управляющих элементов окна
Shift+TabТо же, но в обратном порядке
Клавиши управления курсоромПереход между управляющими элементами группы или перемещение курсора
Shift+клавиши управления курсоромВыделение текста
Shift+InsertСкопировать выделенное в буфер обмена
Shift+DeleteВырезать выделенное в буфер обмена
Ctrl+InsertВставить текст из буфера обмена
EnterЭквивалентно нажатию на активную кнопку. Если активных кнопок нет, нажимается та, что выделена жирной рамкой
EscОтмена, закрытие диалога или окна без выполнения действия
SpaceДля активного элемента типа кнопки или галки эквивалентно щелчку мыши (или действию "Нажать")

Горячие клавиши списка проигрывания

EscЗакрыть окно списка проигрывания
HomeПерейти к началу списка
EndПерейти к концу списка
Page UpПролистать страницу вверх
Page DownПролистать страницу вниз
Курсор вверхПерейти на один элемент вверх (циклически)
Курсор внизПерейти на один элемент вниз (циклически)
Ctrl+Курсор вверхПерейти на один элемент вверх (циклически), не сбрасывая выделение (поэтому визуально данный переход не виден)
Ctrl+Курсор внизПерейти на один элемент вниз (циклически), не сбрасывая выделение (поэтому визуально данный переход не виден)
ПробелИнвертировать выделение текущего элемента (полезно, если необходимо выделить несколько произвольных элементов списка без помощи мыши)
Shift+HomeВыделить от текущего элемента до начала
Shift+EndВыделить от текущего элемента до конца
Shift+Page UpВыделить одну страницу вверх
Shift+Page DownВыделить одну страницу вниз
Shift+Курсор вверхДобавить один верхний элемент к выделенным (циклично)
Shift+Курсор внизДобавить один нижний элемент к выделенным (циклично)
CtrlСовместно со щелчком мыши инвертировать выделение элемента
ShiftСовместно со щелчком мыши выделить диапазон элементов
Ctrl+ShiftСовместно со щелчком мыши добавить к выделенным диапазон элементов
DeleteУдалить из списка все выделенные элементы
InsertВызвать диалог для добавления файлов в список
Shift+Insert, Shift+Щелчок мыши по кнопке ДобавитьВызвать диалог для добавления папки в список
Ctrl+Insert, Ctrl+Щелчок мыши по кнопке ДобавитьВызвать диалог для добавления аудиодорожек с компакт-диска
EnterНачать проигрывание текущего элемента, при проигрывании в случайном порядке, порядок проигрывания будет перестроен
F7Вызвать диалог поиска элемента плейлиста

Также в окне списка проигрывания действуют все клавиши главного окна.
