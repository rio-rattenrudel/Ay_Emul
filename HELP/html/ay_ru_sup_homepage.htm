Официальный сайт

Официальный сайт Ay_Emul расположен по адресу http://ay.strangled.net, архивная историческая версия всё еще хранится по адресу http://bulba.untergrund.net.

На официальном сайте можно найти свежие версии Ay_Emul (включая бета-версии, которые со временем становятся значительно функциональнее предыдущего официального релиза), обшивки, архивы музыки, ссылки на тематические ресурсы, утилиты, документацию по форматам файлов, программированию AY и YM, пакеты для встраивания эмуляции в свои программы, исходные тексты, а также техническую информацию по микросхемам AY-3-8910/12 и YM2149.

Если есть желание писать музыку для этих микросхем, можете скачать с официального сайта редактор Vortex Tracker II под Windows. Это ещё один мой крупный проект, который базируется на движке Ay_Emul и накопившихся за время его написания знаниях о различных форматах музыки ZX Spectrum.
