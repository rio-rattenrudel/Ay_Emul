Hot keys

Terminology

NumpadNumeric keypad

Standard key combinations

Alt+F4Close active window
TabCyclic jumps among window controls
Shift+TabSame in reverse order
Cursor keysCursor moving or selecting group items
Shift+Cursor keysSelecting text
Shift+InsertCopy selected to the system clipboard
Shift+DeleteCut selected to the system clipboard
Ctrl+InsertInsert from the system clipboard
EnterPushes active button. If no, pushes button with bold frame
EscCancel: escaping function or closing dialog without action
SpaceFor active control like button or check box: acts as mouse click (or push)

Hot keys of main window

Playing controls

RLooping melody on/off
ZJump and play previous item in selected playing order
XPlay current item
CPause/continue playing
VStop playing
BJump and play next item in selected playing order
JCall "Jump to time" dialog
Cursor leftSeek to 5 seconds backward
Cursor rightSeek to 5 seconds forward
Cursor upIncrease volume
Cursor downDecrease volume
Next keys work if NumLock is on:
Numpad 2Decrease volume
Numpad 4Jump and play previous item in selected playing order
Numpad 5Start playing current item or pause/continue if was playing
Numpad 6Jump and play next item in selected playing order
Numpad 8Increase volume

Opening files

LCall standard open file dialog
Numpad 0Same (works if NumLock is on)
Shift+L, Shift+Mouse click on Open buttonCall open folder dialog
Ctrl+L, Ctrl+Mouse click on Open buttonCall open audio tracks from CD dialog

Visualization

1Amplitude indicator on/off
2Specter analyzer on/off
TToggle time mode representation

Call other windows

EPlaylist window on/off
PTools window on/off
GMixer window on/off

Playlist hot keys

EscClose playlist window
HomeMove cursor to begin of list
EndMove cursor to the end of list
Page UpMove cursor to one page up
Page DownMove cursor to one page down
Cursor UpMove cursor to one item up (cyclic)
Cursor DownMove cursor to one item down (cyclic)
Ctrl+Cursor UpMove cursor to one item up (cyclic) without resetting selection (therefore this action is not visible)
Ctrl+Cursor DownMove cursor to one item down (cyclic) without resetting selection (therefore this action is not visible)
SpaceInvert selection of current item (useful to select several items without mouse)
Shift+HomeSelect items from cursor to begin of list
Shift+EndSelect items from cursor to end of list
Shift+Page UpSelect one page up
Shift+Page DownSelect one page down
Shift+cursor upAdd item above the cursor to selection (cyclic)
Shift+cursor downAdd item under the cursor to selection (cyclic)
CtrlInvert selection with mouse click
ShiftSelect range with mouse click
Ctrl+ShiftAdd to selection range of items with mouse click
DeleteDelete selected items from playlist
InsertCall open files dialog to add items to playlist
Shift+Insert, Shift+Mouse click on Add items buttonCall open folder dialog to add folder content to playlist
Ctrl+Insert, Ctrl+Mouse click on Add items buttonCall open audio tracks from CD dialog to add them to playlist
EnterPlay selected item, random play order will be recreated
F7Call "Find playlist item" dialog

All main window hot keys work in playlist too.
