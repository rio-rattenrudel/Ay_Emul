Distribution

Ay_Emul is distributed as archives with executable file, BASS/BASSENC libraries, interface translations, skins and documentation (for Windows and Linux, 32- and 64-bit, four archives total) and archive with Ay_Emul source and other required files for compilation executable and help system.

Leave at least executable file for minimal configuration and you'll got a full-featured program (without BASS formats) with English interface.

If you are using Ay_Emul sources, algorithms and ideas, don't forget to credit author.
